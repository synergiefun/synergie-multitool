# Contribuer à SYNERGIE

1. Ouvrez une issue pour décrire le bug ou la proposition avant un changement important.
2. Créez une branche dédiée.
3. Gardez le code compatible avec la version Python indiquée dans le README.
4. Vérifiez la syntaxe avec `python -m py_compile synergie_multitool.py`.
5. N'ajoutez aucun token, webhook, mot de passe, rapport privé ou donnée personnelle aux commits.
6. Décrivez clairement les changements dans la pull request et indiquez les tests réalisés.

Les contributions doivent respecter la vie privée, les conditions d'utilisation des services et les lois applicables.
