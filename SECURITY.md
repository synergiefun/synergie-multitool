# Politique de sécurité

Ne publiez jamais de token Discord, de clé API, de mot de passe, de fichier `.env`, d'URL de webhook ou de données privées dans les issues, discussions ou commits publics.

Pour signaler une vulnérabilité, contactez le mainteneur du dépôt par un canal privé. Évitez de publier des détails exploitables avant qu'un correctif soit disponible.

N'utilisez les outils réseau et d'analyse que sur des systèmes pour lesquels vous disposez d'une autorisation.
